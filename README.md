# Museo-Nueva-Tabarca
Réplica web estática del Museo de Nueva Tabarca (Ayuntamiento de Alicante), en un único archivo HTML autocontenido.
https://necro96.github.io/Museo-Nueva-Tabarca/
El repositorio contiene un solo archivo, `index.html`, con el HTML y el CSS embebidos. La única dependencia externa es la tipografía Cormorant Garamond de Google Fonts.
Basta con abrir `index.html` en el navegador, sin servidor ni instalación.
Este es un proyecto no oficial hecho a mano y a modo de práctica. No tiene relación con el Ayuntamiento de Alicante.
